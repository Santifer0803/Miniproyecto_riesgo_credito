## Librerías escenciales

*importlib*: Para comprobar si alguna librería está instalada.
*matplotlib*: Creación de gráficos.
*numpy*: Manejo de vectores y matrices.
*pathlib*: Gestión de rutas en Python.
*pandas*: Manejo de *dataframes*.
*scipy*: Algoritmos de optimización.
*shiny*: Creación del dashboard.
*subprocess*: Ejecutar comandos externos.
*sys*: Interacción con el sistema y entorno del programa.

## Instrucciones de ejecución

Entrar al directorio (carpeta) en donde se tiene la aplicación.

Ejecutar todo el archivo (generar el dashboard dura un minuto, por si no carga inmediatamente).
